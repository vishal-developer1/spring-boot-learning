# Spring Boot Learning 

A collection of six Spring Boot projects created to learn Java backend development, Spring MVC, JSP, JDBC, REST APIs, and CRUD operations.

## Topics

### 01. First App
- Learn Spring Boot fundamentals.
- Create and run your first Spring Boot application.
- Understand controllers and application configuration.

### 02. MVC JSP
- Learn Spring MVC architecture.
- Integrate JSP views.
- Understand Model, View, and Controller.

### 03. Spring JDBC
- Connect Spring Boot to a database.
- Perform database operations using Spring JDBC.
- Learn SQL queries and data access.

### 04. REST API
- Build REST endpoints.
- Understand HTTP methods and status codes.
- Exchange data using JSON.

### 05. CRUD
- Implement Create, Read, Update, and Delete operations.
- Connect the application to a database.
- Practice repository and service layers.

### 06. MVC
- Build an MVC-based web application.
- Organize controllers, services, and views.
- Practice form handling and validation.

- JDK compatible with the selected Spring Boot version

- IDE such as IntelliJ IDEA, Eclipse, or VS Code

## How to Run a Project

Navigate to the project directory:

```bash
cd 01_first-app
```

Run the application using Maven:

```bash
./mvnw spring-boot:run
```

On Windows, use:

```powershell
.\mvnw.cmd spring-boot:run
```

Repeat these steps for the other project folders.
